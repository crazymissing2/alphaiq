# ⚡ AlphaIQ — AI Trading Academy

The platform that teaches you to trade while you trade.

## Features
- 🧠 AI Mentor powered by Claude — explains every signal in plain English
- 🐳 Whale Flow Map — real-time institutional money tracking  
- 📈 Live AI Signals — RSI, MACD, volume, candlestick patterns
- 🏆 Trading Arena — weekly paper trading competitions
- 📚 Trading Academy — structured lessons taught by AI

## Quick Start
1. Double-click `START.bat`
2. Open `frontend/index.html` in Chrome
3. Create an account and start learning

## Stack
Python · FastAPI · SQLite · WebSockets · Claude AI · Vanilla JS
